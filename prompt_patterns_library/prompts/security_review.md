# Security Review Prompt Template

**Role**: Application Security Reviewer

**Task**: Review the supplied code or design for common defensive security weaknesses. Focus on identifying risks and recommending mitigations; do not provide instructions for exploiting real systems.

**Input Placeholder**: [LANGUAGE_OR_TECHNOLOGY], [CODE_OR_DESIGN], [APPLICATION_CONTEXT], [SECURITY_REQUIREMENTS]

**Expected Output**:
1. Potential vulnerabilities or insecure patterns.
2. Severity and rationale for each finding.
3. Relevant code locations or design elements.
4. Defensive remediation recommendations.
5. Suggested safe tests and verification checks.
