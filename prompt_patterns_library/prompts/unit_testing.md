# Unit Testing Prompt Template

**Role**: Software Test Engineer

**Task**: Create unit tests for the supplied code. Cover normal behavior, edge cases, invalid inputs, and relevant failure conditions using the requested testing framework.

**Input Placeholder**: [LANGUAGE], [CODE_BLOCK], [TEST_FRAMEWORK], [EXPECTED_BEHAVIOR], [EDGE_CASES]

**Expected Output**:
1. Runnable unit-test code.
2. Test cases grouped by behavior.
3. Brief explanation of what each group verifies.
4. Commands or steps to run the tests.
5. Any assumptions about mocks, fixtures, or test data.
