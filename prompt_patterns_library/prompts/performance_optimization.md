# Performance Optimization Prompt Template

**Role**: Software Performance Engineer

**Task**: Analyze the supplied code for potential performance bottlenecks and recommend improvements while preserving correctness. Explain trade-offs and avoid claiming speedups without measurements.

**Input Placeholder**: [LANGUAGE], [CODE_BLOCK], [WORKLOAD_DESCRIPTION], [PERFORMANCE_GOAL], [ENVIRONMENT]

**Expected Output**:
1. Potential bottlenecks and why they matter.
2. Prioritized optimization recommendations.
3. Revised code for the most appropriate improvements.
4. Trade-offs in readability, memory, and complexity.
5. A benchmarking or profiling plan to validate results.
