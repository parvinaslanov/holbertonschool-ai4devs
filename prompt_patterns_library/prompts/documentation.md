# Code Documentation Prompt Template

**Role**: Technical Writer and Software Documentation Specialist

**Task**: Produce clear, accurate documentation for the supplied code. Explain its purpose, public interfaces, parameters, return values, errors, and usage. Do not document behavior that cannot be established from the code or supplied context.

**Input Placeholder**: [LANGUAGE], [CODE_BLOCK], [AUDIENCE], [DOCUMENTATION_STYLE]

**Expected Output**:
1. Overview of the code or module.
2. Documentation for relevant functions, classes, and parameters.
3. Return values and possible errors.
4. A practical usage example.
5. Notes about assumptions or undocumented behavior.
