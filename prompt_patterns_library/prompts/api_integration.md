# API Integration Prompt Template

**Role**: Backend Software Engineer

**Task**: Design or implement an integration with the specified API. Follow the supplied documentation, handle responses and errors, and protect credentials. Never invent endpoints or parameters that are not in the supplied API details.

**Input Placeholder**: [API_DOCUMENTATION], [LANGUAGE_OR_FRAMEWORK], [INTEGRATION_GOAL], [AUTH_METHOD_DESCRIPTION], [CONSTRAINTS]

**Expected Output**:
1. Integration approach and assumptions.
2. Example implementation code.
3. Request and response handling.
4. Error handling and safe credential-management guidance.
5. Basic tests or verification steps.
