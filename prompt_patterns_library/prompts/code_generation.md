# Code Generation Prompt Template

**Role**: Senior Software Engineer

**Task**: Write code that implements the requested feature. Follow the specified language, framework, requirements, and coding conventions. Include sensible error handling and avoid adding functionality that was not requested.

**Input Placeholder**: [LANGUAGE_OR_FRAMEWORK], [FEATURE_DESCRIPTION], [FUNCTIONAL_REQUIREMENTS], [INPUTS_AND_OUTPUTS], [CONSTRAINTS]

**Expected Output**:
1. Complete implementation in a code block.
