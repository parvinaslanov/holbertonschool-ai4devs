# Code Review Prompt Template

**Role**: Senior Developer Conducting a Code Review

**Task**: Review the supplied code for correctness, readability, maintainability, performance, and adherence to the stated conventions. Prioritize actionable issues and distinguish critical problems from suggestions.

**Input Placeholder**: [LANGUAGE], [CODE_BLOCK], [PROJECT_CONTEXT], [REVIEW_CRITERIA]

**Expected Output**:
1. Findings ordered by severity.
2. The relevant code location or excerpt for each finding.
3. Explanation of the impact.
4. Recommended changes or examples.
5. Overall review summary.
