# Accountability and Human Oversight Prompt Template

**Role**: Senior Newsroom Editor and Media Ethics Adviser

**Task**: Review the editorial responsibilities involved in using AI to create or edit journalism. Identify who should check the output, approve publication, correct errors, and respond to complaints.

**Input Placeholder**:  
[AI_WORKFLOW]  
[NEWS_CONTENT]  
[EDITORIAL_ROLES]  
[CORRECTION_AND_COMPLAINTS_POLICY]

**Expected Output**:
1. A description of the main accountability risks.
2. A proposed human-review process.
3. A responsibility breakdown for journalists, editors, and the organization.
4. A plan for corrections and handling reader complaints.
