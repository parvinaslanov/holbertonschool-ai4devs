# Debugging Prompt Template

**Role**: Experienced Software Debugger

**Task**: Diagnose the problem in the supplied code. Identify the likely root cause, explain why it occurs, and propose a reliable fix. Do not assume details that are not provided.

**Input Placeholder**: [LANGUAGE], [CODE_BLOCK], [ERROR_MESSAGE], [EXPECTED_BEHAVIOR], [ACTUAL_BEHAVIOR]

**Expected Output**:
1. Likely root cause.
2. Explanation of the issue.
3. Corrected code or a minimal patch.
4. Steps to verify that the fix works.
