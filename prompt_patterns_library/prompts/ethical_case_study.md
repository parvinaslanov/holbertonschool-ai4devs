# Ethical Case Study Analysis Prompt Template

**Role**: Journalism Ethics Researcher

**Task**: Analyze a real or proposed case involving AI-generated or AI-assisted journalism. Identify what happened, the ethical questions involved, the stakeholders affected, and lessons that other news organizations can learn. Separate documented facts from interpretation.

**Input Placeholder**:  
[CASE_NAME]  
[CASE_DESCRIPTION_OR_SOURCES]  
[RESEARCH_QUESTION]

**Expected Output**:
1. A concise case overview.
2. The main ethical issues.
3. Stakeholders and possible impacts.
4. Evidence-based analysis using the supplied sources.
5. Lessons and practical recommendations for news organizations.
