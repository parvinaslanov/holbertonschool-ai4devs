# SQL Query Writing Prompt Template

**Role**: Database Developer

**Task**: Write a SQL query that answers the requested question using the supplied schema and database dialect. Use clear joins and filters, and state any assumptions about relationships or missing data.

**Input Placeholder**: [DATABASE_DIALECT], [TABLE_SCHEMA], [QUESTION_OR_REQUIREMENT], [SAMPLE_DATA], [CONSTRAINTS]

**Expected Output**:
1. SQL query in a code block.
2. Short explanation of the query logic.
3. Assumptions about keys, relationships, and null values.
4. Optional index or performance considerations where relevant.
