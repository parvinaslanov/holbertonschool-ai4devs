# Prompt Patterns Library

Hey there! This repo holds a collection of reusable prompt templates put together to make working with LLMs a bit smoother for day-to-day dev tasks. 

## Categories Overview
The prompts are split up based on what kind of problem you're trying to solve:
- **Code Quality**: Cleaning up messy code and adding type hints.
- **Docs & Summaries**: Condensing long tech reads or writing API comments.
- **Dev & Debugging**: Writing code snippets from scratch and catching bugs.
