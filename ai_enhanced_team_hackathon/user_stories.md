# User Stories

## Core MVP Stories

1. As a non-technical computer user, I want to describe my computer issue in simple, everyday language without using technical jargon so that I can get help immediately even if I don't know the technical name of the problem.
2. As a user experiencing a system malfunction, I want the AI assistant to analyze my symptoms and list the most likely causes across hardware, Windows, BIOS/UEFI, drivers, and networking so that I understand what is actually going wrong with my device.
3. As a beginner user, I want clear, numbered, step-by-step instructions ordered from safest/easiest to advanced so that I can resolve the issue myself without accidentally damaging my system.
4. As a user with a vague or multi-layered issue, I want the assistant to ask targeted clarifying questions so that it can narrow down the exact cause before giving me a fix.
5. As a cautious user, I want clear warnings before performing sensitive actions so that I don't cause data loss or boot failures.
6. As a returning user, I want to view my past troubleshooting sessions and solutions so that I can reference previous fixes if the same problem happens again.
7. As a user following a troubleshooting guide, I want to mark whether a step worked or failed so that the assistant can immediately pivot to the next probable cause or recommend professional hardware repair.

## Future Scope Stories

8. As a user facing a Blue Screen of Death or BIOS screen, I want to upload a photo or paste an error code so that the AI can extract the exact error details and diagnose it automatically.
