# User Stories — AI Computer & IT Troubleshooting Assistant

## Core MVP Stories

1. **Plain-Language Symptom Submission**
   - **As a** non-technical computer user,
   - **I want to** describe my computer issue in simple, everyday language without using technical jargon,
   - **So that** I can get help immediately even if I don't know the technical name of the problem.

2. **Automated Root Cause Analysis**
   - **As a** user experiencing a system malfunction,
   - **I want** the AI assistant to analyze my symptoms and list the most likely causes across hardware, Windows, BIOS/UEFI, drivers, and networking,
   - **So that** I understand what is actually going wrong with my device.

3. **Step-by-Step Troubleshooting Guide**
   - **As a** beginner user,
   - **I want** clear, numbered, step-by-step instructions ordered from safest/easiest to advanced,
   - **So that** I can resolve the issue myself without accidentally damaging my system.

4. **Interactive Follow-Up Diagnostics**
   - **As a** user with a vague or multi-layered issue (e.g., "my PC won't turn on"),
   - **I want** the assistant to ask targeted clarifying questions (e.g., power lights, beep codes, fan spin),
   - **So that** it can narrow down the exact cause before giving me a fix.

5. **Safety & Risk Warnings**
   - **As a** cautious user,
   - **I want** clear warnings before performing sensitive actions (like editing BIOS/UEFI settings, modifying the Windows Registry, or uninstalling drivers),
   - **So that** I don't cause data loss or boot failures.

6. **Diagnostic Session History**
   - **As a** returning user,
   - **I want** to view my past troubleshooting sessions and solutions,
   - **So that** I can reference previous fixes if the same problem happens again.

7. **Solution Feedback & Escalation**
   - **As a** user following a troubleshooting guide,
   - **I want** to mark whether a step worked or failed,
   - **So that** the assistant can immediately pivot to the next probable cause or recommend professional hardware repair.

## Future Scope Stories

8. **Error Screenshot & Log Analysis**
   - **As a** user facing a Blue Screen of Death (BSOD), BIOS screen, or cryptic error popup,
   - **I want** to upload a photo or paste an error code,
   - **So that** the AI can extract the exact error details and diagnose it automatically.
